# Спокойно в сети — демо-лендинг

Адаптивный учебный лендинг для курса цифровой безопасности для пожилых людей. Это демонстрационный проект для отклика на заказ, не официальный сайт школы.

## Открыть локально

Из этой папки:

```powershell
python -m http.server 8080
```

Откройте `http://localhost:8080`.

## Что реализовано

- светлая адаптивная вёрстка без фреймворков и сборки;
- локальные шрифты и локальное изображение;
- крупный текст, заметный фокус, семантические заголовки;
- мобильное меню и плавная навигация;
- интерактивный разбор мошеннического SMS;
- доступные `details/summary` для вопросов;
- демонстрационная форма с проверкой полей;
- поддержка `prefers-reduced-motion`.

## Важно перед реальной публикацией

- Форма ничего не отправляет и не сохраняет. Подключите защищённую серверную обработку заявок или проверенный сервис.
- Добавьте реальные сведения о курсе, юридические данные и политику обработки персональных данных.
- Замените рабочие тексты после получения уроков заказчика.
- Уберите `noindex, nofollow`, когда сайт будет готов к индексации.
- Не добавляйте API-ключи в HTML, CSS или JavaScript.
- Не публикуйте папку `tools/` вместе с production-файлами, если в ней будут служебные данные.

## Публикация

Статические файлы проекта можно разместить на Vercel, Netlify, GitHub Pages или обычном хостинге. Сборка и переменные окружения не нужны.

## Генерация иллюстрации

Иллюстрация получена через KIE API, модель Nano Banana 2. Скрипт `tools/generate_image.py` принимает путь к локальному файлу с ключом и сохраняет результат в проект. Ключ нельзя переносить в клиентский код или публичный репозиторий.
